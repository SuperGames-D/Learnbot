# Learnbot <img src="learnbot-logo.png" width="30px">
Learnbot is a simple AI bot that you can train with your own information, and it can then respond to questions based on what it has learned.

 

## Getting Started
Visit [the Learnbot website](https://supergames-d.github.io/Learnbot) to chat with Learnbot.
This AI is not pre-trained by default, so you will need to teach it yourself.
However, you can select an example model from a list of pre-trained models to try it out.

### Teaching Learnbot

To teach Learnbot, enter text in the `Teach` box. You should write multiple sentences. For example:
```
The sun is a star.
A cat is an animal.
```
### Asking Questions
After teaching Learnbot, you can ask questions such as:
- `What is the sun?`
- `What is a cat?`

Learnbot will respond using the exact information you provided.

## Models
Each Learnbot version is a new model. By default, opening the Learnbot website will load the most recent model. You can select a different model by adding `?model=` followed by the model name to the URL.
For instance, `?model=v01` will use the first version of Learnbot.

## Advanced features
Learnbot includes several advanced features:
- **Smart Mode**: It allows Learnbot to generate text that isn't quoted exactly from its training data, although it can include incorrect information. Click the `+` icon next to the input box to activate it.
- **Math**: If you ask Learnbot to calculate a basic mathematical operation, it will do it in real time.
- **Feedback System**: You can like or dislike Learnbot's responses to prioritize or correct certain answers in the `Teach` database.
- **Context awareness**: Words in the database inside square brackets `[ ]` will be used by Learnbot to understand the context but will not appear in the response.
